# Windhawk Tray List

Мод Windhawk, который превращает сетку скрытых значков Windows 11 в вертикальный список: значки слева, названия приложений справа.

**Стабильная версия: 0.1.8.6** · [English documentation](README.md)

## Возможности

- Исходные элементы значков сохраняют обработку нажатий, контекстных меню и перетаскивания.
- Сохраняется фон панели Windows; ширина определяется по исходной сетке.
- При изменении числа значков ширина пересчитывается, в том числе при запуске приложений после перезагрузки.
- Длинные названия сокращаются многоточием; длинный список можно прокручивать.
- Скрываются настраиваемые технические окончания `.Root`, `.App`, `.Runner` без смены источника названий Windows.
- Настраивается высота строк. Коррекция правого края закреплена на 1 пикселе.
- Для пересчёта ширины таймеры не добавлены: используются существующие события разметки.

## Совместимость

Проверено пользователем на Windows 11 26H2, сборка **26300.9457**, x64, с английским интерфейсом Windows. 17 октября 2026 года пользователь проверил версию 0.1.8.6 и подтвердил, что всё работает.

Мод использует внутренние интерфейсы панели Windows. Другие сборки и языки интерфейса не проверены. После обновления Windows совместимость может измениться.

## Установка и обновление

1. Установите и откройте [Windhawk](https://windhawk.net/).
2. Нажмите **Create a new mod** и замените шаблон полным содержимым [`tray-overflow-list.wh.cpp`](tray-overflow-list.wh.cpp).
3. Нажмите **Compile** и при необходимости включите мод.
4. Откройте панель скрытых значков.

При обновлении замените код уже установленного мода этим файлом и скомпилируйте. Одновременно должна работать только одна копия мода.

## Настройки

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `hiddenNameSuffixes` | `.Root, .App, .Runner` | Окончания для удаления из подписей через запятую, без учёта регистра. Пустое поле сохраняет исходные названия. |
| `rowHeight` | `33` | Высота строки в пикселях. `0` сохраняет исходную высоту. Пользовательская высота применяется начиная с `20`. |

После изменения настроек закройте и снова откройте панель. Например, `WhatsApp.Root` превращается в `WhatsApp`, а `MicaForEveryone.App` — в `MicaForEveryone`. Внутренние точки и неизвестные окончания сохраняются. Несколько перечисленных окончаний подряд удаляются последовательно; подпись не превращается в пустую строку.

## Если возникла проблема

- **После перезагрузки панель узкая:** проверьте, что включена версия 0.1.8.6 и работает только одна копия мода. Если проблема сохраняется, укажите сборку Windows и помогает ли повторное открытие панели.
- **Неверная геометрия или подсветка:** временно отключите другие моды, меняющие расположение скрытых значков, и сравните результат.
- **Мод перестал работать после обновления Windows:** отключите его в Windhawk. Если исходный вид панели не вернулся, перезапустите Проводник.

В сообщении о проблеме укажите версию мода, сборку Windows, масштаб экрана, другие моды панели трея, шаги воспроизведения и при необходимости приложите скриншот.

## Исходник и проверка

В репозитории оставлен один исходник релиза. Версия 0.1.8.6 основана на подтверждённой стабильной 0.1.8.3 и добавляет настраиваемое удаление технических окончаний названий. Пользователь проверил её работу 17 октября 2026 года. Коррекция правого края закреплена на 1 пикселе; высота строк по умолчанию — 33 пикселя и остаётся настраиваемой. Диагностические версии и сбор метаданных EXE в релиз не входят.

Исходник проходит синтаксическую проверку установленным компилятором Windhawk. Работу в Windows проверил пользователь; автоматическое UI-тестирование не проводилось.
